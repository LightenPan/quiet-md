# 坚果云：连接与发布

实现见 [nutstore-sync.md](nutstore-sync.md)。

## 1. 生成应用密码

1. 登录 [坚果云](https://www.jianguoyun.com/)。
2. 打开右上角账号菜单 → **账户信息**。
3. 进入 **安全选项** → **第三方应用管理**。
4. 点击 **添加应用密码**，名称可填 `Quiet.md`，生成并复制密码。

这个密码不是坚果云登录密码。Quiet.md 不保存登录密码。

## 2. 在 Quiet.md 中连接

1. 打开 `设置 › 文档库`。
2. 在 **坚果云** 组点击 **连接坚果云**。
3. 填写：
   - WebDAV 地址：`https://dav.jianguoyun.com/dav/`
   - 账号：坚果云邮箱
   - 第三方应用密码
   - 远程文件夹：默认 `Quiet.md`；建议用英文/数字名称，兼容性更好
4. 点击 **连接并同步**。

应用会在 WebDAV 根目录下创建远程文件夹。若该文件夹已经存在，会直接加入。

## 3. 测试与发布

- 开发可用 `QUIET_MD_NUTSTORE_DIR` 指定测试状态目录。
- 开发可用 `QUIET_MD_NUTSTORE_PASSWORD_FILE` 指定测试密码文件；正式版本使用系统凭据存储。
- 用临时库和测试坚果云账号完成双设备上传、下载、修改、移动、删除、冲突测试，不要把正式库作为测试对象。
- 免费账号注意 600 次请求/30 分钟和 750 项/请求的限制。
